자주 묻는 질문

어떻게 조작하나요?

휴대폰을 세로로 들고 왼쪽을 누른 채 드래그하면 이동해요. 오른쪽 버튼으로 배를 깔고 슬라이드할 수 있지만, 슬라이드 중에도 눈덩이에 닿으면 게임이 끝나요. 황금 물고기로 에너지를 채우고 비행이 준비되면 비행 버튼을 눌러 잠시 눈덩이 위로 날아갈 수 있어요.

기록과 의상은 어디에 저장되나요?

게임 기록과 의상은 현재 기기에 저장돼요. 게임 계정, 기기 간 동기화, 운영자가 제공하는 클라우드 복원 기능은 없어요. 앱 데이터 삭제, 재설치, 기기 변경 시 기록을 잃을 수 있으며 OS 백업에 따른 동작은 별도예요. 문제가 생겼다면 데이터를 지우기 전에 문의해 주세요. 잃어버린 로컬 기록의 복구를 보장할 수는 없어요.

광고 제거를 구매하거나 복원하려면 어떻게 하나요?

설정 → 게임 서비스에서 광고 제거를 한 번 구매하면 Waddle Rush 전면 광고가 제거돼요. 결제 확정 전에 스토어의 현지 가격이 표시돼요. 구매한 Apple 또는 Google 스토어 계정으로 구매 복원을 선택해 주세요. 서로 다른 스토어로 구매가 이전되지는 않아요. 결제·환불은 해당 스토어에서 관리하며 구매하지 않아도 게임을 할 수 있어요.

순위표와 업적은 어떻게 이용하나요?

설정 → 게임 서비스 → 순위표 또는 업적에서 로그인해요. iOS는 Game Center, Android는 Google Play Games를 사용하며 플랫폼·게임 규칙 버전별로 순위가 구분돼요. 로그인한 상태에서 시작해 종료한 판의 기록을 전송하며, 로그인 전 로컬 최고 기록을 처음 로그인할 때 자동으로 올리지는 않아요. 전송 실패 시 같은 계정으로 재시도해요. 옷장이나 전체 저장 데이터를 백업하는 기능은 아니에요.

광고는 언제 나오나요?

한 판을 마친 뒤 직접 시작 또는 재도전을 누를 때 전면 광고가 나올 수 있어요. 플레이 도중이나 게임오버 직후에 자동으로 표시하지는 않아요. 앱을 다시 켜도 광고 차례는 유지돼요. 네트워크, 동의 요건, 광고 제공 상태에 따라 표시 여부가 달라지고 닫기 버튼은 광고 제공자가 관리해요.

언어와 소리를 바꿀 수 있나요?

설정에서 기기 언어를 따르거나 16개 언어 중 하나를 선택할 수 있어요. 배경음악과 효과음의 크기도 각각 조절할 수 있어요.

광고 개인정보 선택을 바꾸려면 어떻게 하나요?

Google 동의 시스템에서 필요한 경우 설정에 개인정보 선택 버튼이 표시돼요. 여기서 선택을 다시 확인할 수 있어요. 기기 자체의 광고·개인정보 설정도 이용할 수 있으며 자세한 내용은 개인정보처리방침에서 확인해 주세요.

데이터를 삭제하거나 개인정보 관련 요청을 하려면요?

기기가 제공하는 앱 저장공간 설정에서 데이터를 지우거나 앱을 삭제해 로컬 기록을 제거할 수 있어요. 사용 가능한 백업이 없으면 되돌릴 수 없고, OS 백업은 별도로 관리해야 해요. 삭제할 게임 계정은 없어요. 문의 이메일의 열람·정정·삭제는 문의했던 주소에서 help.projectunknown.team@gmail.com로 요청해 주세요. 광고 데이터는 Google의 정책과 제어 기능에 따라 관리돼요. 스토어 구매·플랫폼 점수·SDK 기록은 Apple, Google 또는 Unity에서 별도로 관리하며 로컬 데이터 삭제로 함께 지워지지는 않아요.
